## Alur Pengerjaan
1. **Wireframe konsep** — menentukan urutan bagian halaman: header, hero, tentang program, fasilitas, informasi pendaftaran, dan footer.
2. **Mini design system** — menetapkan aturan visual yang dipakai di seluruh halaman:
   - Warna utama biru `#173F73` dengan aksen kuning `#E7A72D`
   - Font Plus Jakarta Sans
   - Spacing kelipatan 8px
   - Button dan input dengan tinggi minimal 48px
3. **Mockup final** — menerapkan design system ke dalam tampilan lengkap:
   - Hero *Bangun Masa Depan Bersama Teknologi Digital*
   - Tiga kartu program: Web Development, Software Development, Data & Technology
   - Tiga kartu fasilitas: Laboratorium Komputer, Ruang Pembelajaran, Ruang Diskusi

## Catatan
Di versi desktop, konten tersusun dalam beberapa kolom dengan navigasi horizontal. Di versi mobile, konten menjadi satu kolom dengan menu hamburger dan tombol selebar layar. Gambar pada mockup masih berupa placeholder.
